# Archived Sprints

Final snapshots of completed sprints, one file each (`SPRINT-NNN.md`), copied from `CURRENT_SPRINT.md` at sprint close — content verbatim **except relative links, which gain one `../` level**, because the archive sits a directory deeper and a byte-for-byte copy leaves every link broken ([RETRO-SPRINT-001](../retrospectives/RETRO-SPRINT-001.md) action 4). Each archive says so in a header comment by [`retrospective`](../../skills/retrospective/SKILL.md) (or `plan-sprint` if a retro was skipped — which itself should be raised in the next retro).
