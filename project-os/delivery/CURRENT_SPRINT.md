# Current Sprint

> **No active sprint.** Run [`plan-sprint`](../skills/plan-sprint/SKILL.md) to start one — it replaces this file's content using [`templates/SPRINT_TEMPLATE.md`](../templates/SPRINT_TEMPLATE.md). When a sprint ends, its final state is archived to `delivery/sprints/SPRINT-NNN.md` before this file is reset.

This file is the **authoritative list of work committed to the current sprint**. Rules that apply whenever a sprint is active:

- Agents MUST NOT add work here without following [WoW §7](../governance/WAY_OF_WORKING.md) (Discovered / Unplanned Work, with justification).
- The Work table mirrors ticket status; ticket files are authoritative for status, this file is authoritative for *what is committed* and *the sprint goal*.
- Blockers and escalations awaiting humans are listed here so a human can scan one file to see where the team is stuck.

Sprint numbering: `SPRINT-001`, `SPRINT-002`, … Next sprint: **SPRINT-002**.
