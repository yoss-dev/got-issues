# apps/

Deployable applications and services — one directory per app, each self-contained with its own build/run/test entry points and a README per [documentation standards](../project-os/standards/DOCUMENTATION.md). Shared code belongs in [`libs/`](../libs/README.md), not copied between apps. Tailored (or pruned) during [`bootstrap-project`](../project-os/skills/bootstrap-project/SKILL.md).
